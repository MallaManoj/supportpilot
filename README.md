# SupportPilot

AI-powered customer support and troubleshooting platform.

## Goal

SupportPilot helps customers get answers from product documentation
using retrieval-augmented generation (RAG), while allowing low-confidence
questions to be escalated to support agents.

## Planned Technology

- Next.js
- TypeScript
- Tailwind CSS
- Python
- FastAPI
- PostgreSQL
- pgvector
- Redis
- Pytest
- Playwright
- Docker
